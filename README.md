# House-Price-Prediction
House Price Prediction using Python and Machine Learning with Linear Regression, data visualization, and model evaluation.
House Price Prediction Using Machine Learning
Project Overview

This project predicts house values using Python and Machine Learning. It was developed as part of the Yuva Intern Week 6 Integrative Capstone Project.

The project uses a Linear Regression model to estimate house values based on housing-related features.

Objectives
Analyze and understand the housing dataset.
Perform data preprocessing and exploratory data analysis.
Create visualizations to identify patterns in the data.
Train a Linear Regression model.
Evaluate model performance using regression metrics.

Model Performance

The model was evaluated using the following metrics:

Mean Absolute Error (MAE): 0.53
Root Mean Squared Error (RMSE): 0.75
R-squared Score: 0.5758

The R-squared score indicates that the model explains approximately 57.58% of the variation in the target values on the test dataset.

Note: MAE and RMSE are expressed in the units of the dataset's target variable.

Results
The project successfully demonstrates a basic machine learning workflow for house price prediction. The model provides a baseline, and its performance may be improved through feature engineering, comparison with other algorithms, and hyperparameter tuning.
